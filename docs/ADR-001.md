# ADR-001: Implementación de orquestación con Kubernetes y Pipeline CI/CD

**Fecha:** 2026-06-17  
**Estado:** Aceptado  
**Decisor:** Daniel Irigoyen  

## Contexto y problema
El sistema de gestión hotelera debe asegurar alta disponibilidad y escalabilidad automática ante variaciones en la carga de tráfico de usuarios, evitando el despliegue manual propenso a errores.

## Opciones consideradas
1. **Despliegue Manual en VPS:** Fácil de configurar, pero sin tolerancia a fallos ni autoescalado.
2. **Kubernetes (K8s):** Ofrece alta disponibilidad, orquestación, autoescalado (HPA) y portabilidad entre proveedores cloud.

## Decisión tomada
**Opción seleccionada:** Kubernetes con despliegue automatizado vía GitHub Actions (CI/CD).

## Justificación
* **Escalabilidad:** El HPA (Horizontal Pod Autoscaler) permite ajustar automáticamente las réplicas del backend según el uso de CPU.
* **Automatización:** El pipeline de CI/CD elimina pasos manuales, garantizando que cada cambio pase por pruebas unitarias (`jest`) antes de llegar a producción.
* **Seguridad:** Uso de Kubernetes Secrets para desacoplar credenciales de la base de datos (Supabase) del código fuente.

## Consecuencias
* **Positivas:** Sistema resiliente, escalable y con despliegue continuo.
* **Negativas:** Curva de aprendizaje y complejidad de configuración inicial superior a un servidor simple.
